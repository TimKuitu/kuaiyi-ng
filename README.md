## ⚡ v3.0 纯 Rust 架构重构宣言

快译NG 在 **v3.0.0** 迎来了诞生以来最彻底的一次蜕变——**告别过去的 C + Nim 混合架构，全栈采用纯 Rust 重新设计与实现！！**

- **为什么重构？**  
  在历史版本中，C 核心网络/文本引擎与 Nim/wNim 界面层通过 FFI 绑定，跨语言边界维护成本高，多线程栈跟踪与原生控件竞态曾带来潜在的排障难题。
- **重构成效：**  
  - 🦀 **全栈纯 Rust 实现**：从底层 WinINet 网络通讯、JSON 路径解析、INI 配置系统、命名缩减算法，到上层 Modern UI 纯原生渲染管线，全部使用 Rust 重写。
  - 🪶 **单文件体积骤减约 50%**：可执行文件由原先的 1.3 MB 暴降至 **约 700 KB**（比旧版轻量近一倍）。
  - ⚡ **毫秒级极速响应**：内存占用（常驻私有内存）降至 **< 15 MB**，冷启动耗时 **< 20 ms**，按一下热键窗口即刻随鼠标召唤，告别任何卡顿。
  - 🛡️ **内存与并发绝对安全**：借助 Rust 严苛的所有权与类型系统，彻底终结了空指针崩溃、数据竞态和内存泄漏。

> 📌 **分支变更说明**：本项目的默认主分支 `main` 从 v3.0.0 起全面代表 **纯 Rust 架构代码**；原 C + Nim 的历史实现已正式归档至废弃分支 `legacy-c-nim`，供历史追溯与查阅。

## 🌟 核心功能特性

### 1. 现代化桌面交互与流光视觉 (Modern UI)
- **原生深浅色自适应**：支持跟随系统主题切换或手动锁定，提供优雅的暗黑流光卡片与明亮质感。
- **无边框毛玻璃体验**：细致的微投影、平滑悬浮动画、高对比度图标与圆角胶囊导航，告别传统旧式 Win32 灰白窗口。
- **高分屏 Per-Monitor V2 DPI 完美协同**：原生 DPI 动态感知，在 100% ~ 250% 任意高分缩放比例下字号、图标与留白均锐利清晰。

### 2. 毫秒级截图标注与智能取词 (Snip & Annotate)
- **多显示器协同**：自动枚举所有物理屏幕与虚拟桌面范围（跨双屏/多屏、不同缩放比例自适应），自动排除底部任务栏误截。
- **画笔级自由模糊与马赛克**：
  - 独创 **全图网格对齐马赛克画笔** 与 **双轮快速滑动窗口盒式模糊（Box Blur）画笔**；
  - 像真实画笔一样自由涂抹任何敏感信息，告别死板的矩形遮罩；
  - 配备圆形笔刷实时光标预览，粗细随心调控。
- **专业标注工具箱**：矩形、椭圆、带平滑尖角的指示箭头、自由涂鸦笔刷、动态文本标注，支持无限级撤销与原图/标注图一键复制。

### 3. 多引擎翻译与智能容灾回退
- **必应免费词典与翻译（开箱即用）**：
  - 无需申请任何 Key 即可免费中英互译；
  - 查英文词时自动展示音标、词性释义与网络释义，中文附带拼音标注。
- **AI 智能大模型翻译（可选）**：
  - 兼容 OpenAI 格式，内置 DeepSeek、OpenAI、Moonshot、本地 Ollama 等主流预设；
  - 支持 API Key 密码箱脱敏查看。
- **百度翻译开放平台官方 API（可选）**：支持标准 MD5 验签与自定义接口。
- **智能三级回退链**：按 **AI → 百度 → 必应** 自动切换；遇网络波动或额度耗尽自动静默兜底，标题栏实时呈现命中的翻译引擎。

### 4. 离线编程命名转换工具 (Code Naming Reducer)
- **短语直出标识符**：输入日常中文或英文短语，双击或按下快捷键直接生成规范的编程变量/函数/类名（如 `串口初始化程序` → `uartInit`）。
- **两大风格 × 七大对象**：
  - **风格**：`snake_case`（下划线）与 `camelCase`（驼峰法）；
  - **对象**：局部变量、全局变量（`g_` / `gXxx`）、静态变量（`s_` / `sXxx`）、指针变量（`p_` / `pXxx`）、结构体类型（`_t` / `PascalCase`）、宏常量（`SCREAMING_SNAKE`）、函数。
- **全内置代码命名词库**：
  - 内置 60+ 组通用缩写、65+ 常见泛词自动剔除、120+ 软硬件高频专业词汇映射；
  - 自动避开 C / C++ / Rust / Go / Python / Java / C# 等 9 大主流语言保留字。

### 5. 可视化词库深度定制
- 设置页提供 **「缩略词」「忽略词」「常用词」** 三张可实时编辑的词库配置表。
- 内置词条与用户自定义词条统一合并展示，支持直接新增、改写或禁用内置词条，支持关键字毫秒级即时搜索过滤。

### 6. 便捷的桌面集成与快捷键
| 默认快捷键 | 功能说明 | 特色选项 |
| :--- | :--- | :--- |
| `Ctrl + Alt + F` | 唤醒 / 隐藏主窗口 | 可选“随鼠标位置居中召唤”、“唤醒时自动清空” |
| `Ctrl + Alt + D` | 启动屏幕截图标注 / 翻译 | 跨屏全景截取、自由画笔模糊、智能框选 |
| `Ctrl + Alt + C` | 快速命名复制 | 直接提取输入框短语转换为命名并送入剪贴板 |
| `Ctrl + Alt + ↑` | 翻阅上一条历史记录 | 本地持久化去重历史（上限 200 条） |
| `Ctrl + Alt + ↓` | 翻阅下一条历史记录 | 向下定位最新记录 |

## 🛠️ 本地编译与构建

快译NG v3.0 拥抱现代化的 Rust 工具链，无需配置复杂的 Nim 环境。

### 1. 环境准备
- **Rust 工具链**：1.75+（推荐 `stable-x86_64-pc-windows-msvc` 或 `stable-x86_64-pc-windows-gnu`）
- **MinGW / LLVM**（可选）：用于 `windres.exe` 编译图标资源

### 2. 编译 Release
```bash
# 1. 编译 Windows 应用程序图标资源
windres.exe app.rc -O coff -o target/app.res

# 2. 编译优化体积的 Release 版本
cargo build --release

# 编译产物位于 target/release/kuaiyi-ng.exe
```

### 3. 打包安装包（可选）
项目根目录提供 NSIS 安装脚本：
```bash
makensis.exe installer.nsi
# 生成 快译NG-安装包.exe
```
