# 快译NG (KuaiYiNG)

轻量级 Windows 桌面中英互译与编程命名工具——按一下热键，窗口出现在鼠标旁；查词、翻句、截屏译图、一键生成代码标识符，一气呵成。

纯原生桌面应用，无浏览器内核、无外部运行库依赖，单文件约 **1.27 MB**，开箱即用。

---

## 功能特性

### 1. 多引擎翻译与智能回退
- **必应免费翻译（开箱即用）**：无需任何密钥即可中英互译；查询英文单词时自动展示必应词典结果（英/美音标、词性释义、网络释义），中文结果附带拼音。
- **AI 翻译（可选）**：兼容 OpenAI 接口格式，内置 DeepSeek、OpenAI、Moonshot、本地 Ollama 等预设，填写接口地址、密钥与模型即可使用；支持密钥脱敏/明文切换查看。
- **百度翻译 API（可选）**：填写开放平台 AppID 与密钥即可使用，支持自定义接口地址。
- **三级回退链**：默认按 **AI → 百度 → 必应** 顺序自动切换，前级未启用或请求失败时自动兜底并在结果前注明原因；**输入包含中文时自动跳过 AI**，直接走百度 → 必应。标题栏实时提示当前命中的引擎。
- **便捷操作**：提供 `中 > 英`、`英 > 中`、`翻译`（自动识别方向）三个按钮，输入框回车即译；等待期间再次触发支持软取消并立即发起新翻译。

### 2. 截屏翻译（v2.3.0 新增）
- **一键框选翻译**：按全局快捷键（默认 `Ctrl+Alt+D`）进入全屏框选状态（支持多显示器桌面），框选英文区域后自动识别并翻译为中文。
- **原图直接替换**：自动擦除框选区域内的原英文，并在对应位置覆盖渲染中文译文，保留原图排版观感。
- **结果悬浮窗**：支持 **原图 / 译图一键切换**、**复制译文**、**复制译图到剪贴板**、**重新框选** 以及自由拖拽移动；任意时刻按 `ESC` 或右键均可退出。

### 3. 编程命名复制（本地离线）
- **短语直出标识符**：无需先翻译，双击输入框/结果区或按下复制热键，即可将中英文短语直接缩减为合法变量名/函数名，自动写入剪贴板并回显结果（例如 `串口初始化程序` → `uartInit`）。中译英完成后，也可直接对译文执行同样的命名缩减。
- **两种命名风格**：`snake_case` 与 `驼峰法`。
- **七种命名对象**：局部变量、全局变量（`g_` / `gXxx`）、静态变量（`s_` / `sXxx`）、指针变量（`p_` / `pXxx`）、结构体类型（`_t` 后缀 / 大驼峰）、宏常量（全大写下划线）、函数。
- **智能缩减与校验**：自动剔除泛词、套用编程惯用缩写与高频常用词映射、按词数/字符数预算（默认 4 词 / 40 字符）裁剪，并自动避开 C / C++ / C# / Java / JS / Python / Go / Rust / Nim 保留字。

### 4. 可视化词库自定义
- 设置页内置 **「缩略词」「忽略词」「常用词」** 三张可编辑词库表，完整展示内置词条（60 组缩写、65 个泛词、120+ 常用词）与用户自定义条目。
- 支持直接 **新增、修改、删除**（可禁用内置缩写、保留内置泛词、覆盖内置中英映射），并支持 **实时搜索过滤** 与滚轮浏览，保存后立即生效。

### 5. 全局热键与桌面交互
- **5 组可自定义全局热键**（设置页支持可视化按键录制）：

| 功能 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 显示 / 隐藏窗口 | `Ctrl+Alt+F` | 可选“召唤时出现在鼠标旁”“召唤时清空输入与结果” |
| 上一条历史记录 | `Ctrl+Alt+↑` | 浏览本地查询历史（去重，最多保留 200 条） |
| 下一条历史记录 | `Ctrl+Alt+↓` | 向下翻阅历史记录 |
| 复制命名 / 单词 | `Ctrl+Alt+C` | 一键生成命名并复制到剪贴板 |
| 截屏翻译 | `Ctrl+Alt+D` | 全屏框选英文并在原图上替换中文 |

- **交互细节**：可选“双击输入区清空输入区”（默认关闭；关闭时双击直接生成命名复制，双击结果区始终为命名复制）；支持窗口置顶、关闭时隐藏至托盘或直接退出、开机自启动（可选启动后隐藏）以及单实例自动唤醒。

### 6. 界面缩放与在线更新
- **7 档全局缩放（75% ~ 200%）**：字号、控件、行距及主/设置窗口尺寸等比缩放，支持手填主窗口宽高或恢复默认，保存即生效。
- **一键检查更新**：设置页支持检查 GitHub Releases 新版本，并可直接下载拉起安装包。

## 内存占用与性能表现

以下数据基于 **v2.3.0** 在 Windows 环境下实测：

| 指标 | 实测表现 |
| --- | --- |
| **程序体积** | 便携版单文件约 **1.27 MB**（1,336,166 字节），安装包约 **553 KB** |
| **内存占用（空载/常驻）** | **私有内存约 6.45 MB**（工作集约 27.09 MB，含系统共享组件），远低于常见的浏览器内核/Electron 类工具 |
| **启动速度** | 毫秒级冷启动，原生控件即时渲染，无白屏等待 |
| **本地命名缩减** | 纯本地离线计算，单次转换微秒/亚毫秒级响应（55 组综合测试集瞬时完成） |
| **网络翻译响应** | 后台异步执行，翻译期间界面零卡顿；必应首轮冷启动握手并完成翻译实测约 **3 秒**（会话建立后后续查询更快） |
| **截屏翻译开销** | 复用系统原生识别能力就地渲染，无需加载大型离线 OCR 模型，不常驻额外高额内存 |

## 常见问题与反馈

- **无语音朗读**：当前版本专注于文字与截屏翻译及编程命名，不包含 TTS 发音功能。
- **日志与排障**：程序会在缓存目录 `fastT\` 下保存 `run.log` 与 `run.last.log`（不含 API 密钥），遇到异常或闪退时可将这两个日志文件附带提交反馈。
