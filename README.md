# 快译NG (KuaiYiNG)

轻量级 Windows 中英互译工具——按一下热键，窗口出现在鼠标旁，查词、翻句、按驼峰命名复制，一气呵成。

**纯 C 核心 + Nim/wNim 原生控件界面**，单文件约 1.3MB，**私有内存约 4MB**，
无浏览器内核、无运行时依赖，开箱即用。

## 功能特性

### 翻译

- **必应免费翻译**（无需任何密钥）：句子走网页翻译接口；英文单词自动查必应词典
  （英/美音标 + 释义 + 网络释义 + 拼音）
- **AI 接口翻译（可选）**：支持一切 OpenAI 格式接口（DeepSeek / OpenAI / Moonshot / 本地 Ollama 等），
  内置预设下拉，填地址、密钥、模型即可
- **百度翻译 API（可选）**：填开放平台的 AppID + 密钥即可（免费标准版），支持自定义接口地址
- **三级回退链**：AI → 百度 → 必应免费，前面的未启用或失败自动切换到后面的，失败原因会附在结果前；
  **输入含中文时自动跳过 AI**，直接走 百度 → 必应 二级链
- 三个按钮 + 回车即译：`中 > 英`、`英 > 中`、`翻译`（按内容自动判断方向）

### 命名复制（面向写代码）

- **双击/热键直接出标识符**：不用先翻译，输入框里的中英文短语直接缩成合法标识符，
  自动进剪贴板并回显结果区（`串口初始化程序` → `serialPortInit`）
- **命名风格**下拉：snake_case / 驼峰法
- **命名对象**下拉：局部变量 / 全局变量 / 静态变量 / 指针变量 / 结构体类型 / 宏常量 / 函数，
  按 C 惯例自动套前缀与大小写（全局 `g_`、静态 `s_`、指针 `p_`、宏全大写、结构体 `_t` 后缀）
- 译中→英后，热键/Ctrl+双击复制的是英文译文并做同样的本地命名缩减

### 召唤与清空

- **全局热键**（可视化录制、可自定义）：
  - `Ctrl+Alt+F` 显示/隐藏窗口（可勾选"召唤时出现在鼠标旁边"）
  - `Ctrl+Alt+↑/↓` 翻历史记录　`Ctrl+Alt+C` 复制单词
- **开关：热键召唤时清空输入区和结果区**——每次唤出都是干净的起点
- **开关：双击输入区＝清空输入区**（默认关；关闭时双击＝生成命名并复制，双击结果区始终是复制命名）

### 词库自定义

- 设置页「缩略词」「忽略词」「常用词」三页：内置词条（缩略 60 组 / 泛词 65 个 / 常用词 120+）全部列出，
  **可以直接改、可以删**——删缩略行 = 这个词不再缩写；删忽略行 = 保留它；常用词页改英文 = 覆盖内置映射，
  也能加全新词条；保存立即生效
- 数据存 `fastT\custom_abbr.txt` / `custom_ignore.txt` / `custom_preferred.txt`，纯文本可手改
  （只记与内置不同的条目，文件保持精简）；列表支持滚轮与拖动滚动条

### 界面与设置

- 设置页六个页签：通用设置 / 快捷按键 / 翻译接口 / 缩略词 / 忽略词 / 常用词；
  **点「保存设置」不关窗口**，提示直接弹在设置窗口上，可连续修改连续保存
- **字体缩放 75% ~ 200%**（七档）：字号、控件、行距、两个窗口的尺寸整窗等比缩放，保存立即生效；
  窗口大小可手填（宽 × 高）也可恢复默认
- 窗口置顶、关闭行为（隐藏到托盘 / 退出）、开机自启动（可选启动后隐藏）、缓存目录可改
- 查询历史（去重、200 条）、托盘常驻（双击显示/隐藏、右键菜单）
- **检查更新**：设置页一键查 GitHub Releases 新版本，可直接下载并拉起安装包
- 单实例保护 + 自愈：重复启动自动唤醒已有窗口，残留进程自动清理

## 实现原理

### 总体架构

```
core\   纯 C 核心（gcc -O2 静态链入，无 DLL 依赖）
        bing.c   必应免费翻译 + 必应词典（IG/IID/token 会话管理）+ 翻译回退链
        ai.c     OpenAI 格式 AI 翻译（DeepSeek/OpenAI/Moonshot/Ollama 等）
        baidu.c  百度翻译开放平台（MD5 签名）
        md5.c    MD5（RFC 1321）
        update.c 检查更新（GitHub Releases 查询 + 安装包下载）
        http.c   WinINet 会话（自动 Cookie）
        json.c   极简 JSON 路径取值器
        cfg.c    INI 配置（GBK 编码）
        hist.c   查询历史
        str.c/fmt.c  编码转换 / 单词命名格式化
ui\     Nim + wNim 原生控件界面
        main.nim        主窗口 + 设置 + 热键 + 托盘 + 后台翻译线程
        fastcore.nim    C 核心绑定（{.compile.} 直接编译 C 源码）
        naming_reducer.nim  命名缩减（泛词/缩写/常用词/预算/保留字）
```

**线程模型**：UI 是 wNim 单线程消息循环；每次翻译由 `CreateThread` 创建裸线程执行 C 核心
（线程内不触碰 Nim GC，只通过 `PostMessage` 把结果指针发回 UI 线程），界面永不因网络请求卡顿。

### 翻译链路

1. UI 层只决定"启用哪些引擎"：AI 需启用且有地址+密钥；百度需启用且有 AppID+密钥；
   **输入含中文（UTF-8 字节级 CJK 扫描）时强制将 AI 置为未启用**
2. C 核心 `fy_translate_chain` 按 AI → 百度 → 必应 顺序尝试，参数为空的段自动跳过；
   某级失败把原因拼进结果备注（如 `AI：超时；`），全部失败才报错
3. **必应免费接口**（无需密钥）：
   - `GET cn.bing.com/translator` 提取会话参数（IG / IID / token / key，约 1 小时有效，自动刷新）
   - `POST /ttranslatev3` 表单携带 token/key 获取译文与拼音
   - 单词走 `cn.bing.com/dict/search` 解析音标与释义
4. **百度**：MD5 签名按官方规则（签名用原文、传输只编码一次），单次请求 ≤6000 字节
5. **AI**：OpenAI `/chat/completions` 格式（temperature 0），系统提示词约束"只输出译文本身"

### 命名缩减（本地离线，不联网）

输入短语依次经过：

1. **泛词删除**：内置 65 个泛词（"程序""系统""功能"…）直接剔除，忽略词页可定制保留
2. **惯用缩写**：内置 60 组编程惯用缩写（initialization→init、configuration→config…），缩略词页可增删
3. **常用词映射**：内置 120+ 嵌入式高频词（串口→uart、蜂鸣器→buzzer、显示→display…），
   词库词不删泛词、不做缩写，超预算裁剪时优先保留
4. **长度预算裁剪**：默认 4 词 / 40 字符（config `[复制单词]` 可调），超限从低权重词开始裁，
   **绝不静默截断**——放不进预算时标题栏提示原因并记日志
5. **合法性校验**：标识符字符集检查 + 九语言保留字（C/C++/C#/Java/JS/Python/Go/Rust/Nim）查重，
   冲突自动加 `_` 后缀

### 配置与数据（均在缓存目录 `fastT\`）

| 文件 | 内容 |
| --- | --- |
| `config` | GBK 编码 INI：通用设置 / AI翻译 / 百度翻译 / 快捷按键 / 复制单词 等 |
| `custom_abbr.txt` / `custom_ignore.txt` / `custom_preferred.txt` | 自定义词库，只记与内置不同的条目（`原词=-` 禁用、`+词` 保留） |
| `history.txt` | 查询历史（UTF-8 每行一条、去重、200 条） |
| `run.log` / `run.last.log` | 运行日志：每次启动把上次记录轮换为 run.last.log；不含密钥，被翻译原文只留前 48 字节预览；闪退时自动追加异常码/地址/线程信息 |

## 从源码构建

依赖：

- [MSYS2](https://www.msys2.org/) MinGW-w64（gcc ≥ 13、windres）
- [Nim 1.6.20](https://nim-lang.org/install_windows.html)（**必须是 1.6.x**，2.x 与 wNim 不兼容）
- [wNim](https://github.com/khchen/wNim)、[winim](https://github.com/khchen/winim)、[memlib](https://github.com/khchen/memlib)
- [NSIS 3.x](https://nsis.sourceforge.io/)（仅打安装包需要）

```bat
git clone https://github.com/TimKuitu/kuaiyi-ng.git
cd kuaiyi-ng
:: 编译主程序（按 build.bat 内注释调整依赖路径后）
build.bat
:: 打安装包
makensis installer.nsi
```

> 注意：必须以 `-d:release` 构建。调试版每个 Nim 过程都要读写全局 framePtr，
> 翻译裸线程会和 UI 线程竞态写坏它，导致随机 0xC0000005 闪退。

## 说明

- 发音（TTS）功能未包含
- 配置文件 `fastT\config` 为 GBK 编码的 INI（段/键名见程序设置）
- 遇到闪退：把 `fastT\run.log` 和 `fastT\run.last.log` 两个文件发给开发者即可定位
- 详细开发记录见 [说明.md](说明.md)
